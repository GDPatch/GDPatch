<Steps>
1. [Download the latest release of GDPatch](https://github.com/GDPatch/GDPatch/releases/latest/download/gdpatch_loader.dll).
2. Copy `gdpatch_loader.dll` into your game install and rename it to `winmm.dll`.

   <FileTree>
    - game.exe
    - **winmm.dll**
   </FileTree>

   If you have [file extensions disabled in Windows](https://support.microsoft.com/en-us/windows/experience/storage-filemanagement/common-file-name-extensions-in-windows), the file will simply be named `gdpatch_loader`, and you should rename it to `winmm` in that case.

3. Start the game.
</Steps>

<Aside>
  Some antivirus software (like Microsoft Defender) will flag GDPatch as a false positive. You may need to explicitly
  allow `winmm.dll` in your antivirus software.

  These false positives are triggered because GDPatch performs filesystem-level hooking for the Godot engine, which is
  also often used in malicious applications. Rest assured that **GDPatch is safe and is not malware**.
</Aside>
