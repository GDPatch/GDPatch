<Steps>
1. [Download the latest release of GDPatch](https://github.com/GDPatch/GDPatch/releases/latest/download/libgdpatch_loader.dylib).
2. Start the game from a terminal with `DYLD_INSERT_LIBRARIES` set to the path to `libgdpatch_loader.dylib`:

   ```bash
   DYLD_INSERT_LIBRARIES=/path/to/libgdpatch_loader.dylib ./game
   ```
</Steps>
