# GDPatch

A versatile cross-platform cross-version Godot mod loader, built around script patching and runtime hooks.

For more information, see [the docs](https://gdpatch.dev/), or join [the Discord server](https://discord.gg/dBNktMCeuT).

## Acknowledgements

GDPatch uses code from the following projects:

- [Godot RE Tools](https://github.com/GDRETools/gdsdecomp). Most of the GDScript text reconstruction logic was ported from their implementation, as well as a lot of useful reference code.
- [GDWeave](https://github.com/NotNite/GDWeave). The "spiritual predecessor" to GDPatch.

GDPatch wouldn't be possible without these projects and the effort put in by their contributors. Thank you! <3
